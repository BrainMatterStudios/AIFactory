# AIFactory 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship AIFactory 0.3.0 with Design IR v1, deterministic design authority, honest execution capabilities, normalized analyzer evidence, exact design approval, read-only status, and a backward-compatible release path.

**Architecture:** Add pure, dependency-free design contracts beneath `software_factory/core/design`; keep analyzer integrations in a bounded `software_factory/analyzers` package; and persist immutable design and gate generations through controller-owned stores beneath `.factory`. A focused `build/design_phase.py` sequences design authoring, analyzers, the deterministic gate, and exact approval, while `run_build` selects that path only for `design_ir_v1` and leaves `legacy_plan` unchanged.

**Tech Stack:** Python 3.10+, standard library, existing AIFactory adapter and controller-state patterns, pytest, Ruff 0.16.0, setuptools, GitHub CLI for separately approved publication steps.

**Authoritative specification:** `docs/superpowers/specs/2026-08-10-aifactory-0.3.0-design-authority-design.md`. If this plan and that specification disagree, stop and amend the plan through review; do not silently reinterpret the approved design.

## Global Constraints

- Keep `project.dependencies = []`; 0.3.0 adds no hard runtime dependency.
- Design IR v1 is strict JSON with `schema_version: 1`; unknown fields, duplicate keys or IDs, bool-as-int values, invalid references, and unsupported versions fail closed.
- The Design IR SHA-256 identity excludes only `generated_at`; every other field is identity-bearing.
- Contract v2 and `findings_v2` remain unchanged.
- Missing `factory.build.design_protocol` means `legacy_plan` with a migration warning; new scaffolds select `design_ir_v1`.
- A required missing, stale, malformed, mismatched, timed-out, or unavailable input never becomes a pass.
- Models, runners, analyzers, labels, status views, and generated prose cannot create authority.
- Design approval binds repository, issue, Design IR digest, and exact parent Contract digest.
- `factory status` and inspection commands must not create, repair, or rewrite controller state.
- Preserve Python 3.10 support, zero-hard-dependency installation, v0.x legacy-plan compatibility, public-content scanning, and the existing merge/deploy ceiling.
- Do not implement Review Canvas, managed configuration, code-to-design extraction, automated improvement admission, memory, packs, merge, deploy, or publication authority.
- Use TDD for every behavior change and make the focused tests pass before each commit.
- Every commit is conventional and includes `Co-Authored-By: Codex <codex@openai.com>`.
- Stop for a fresh operator approval before push, pull-request creation, merge, tag creation or push, GitHub release creation, or package-registry publication.

```python
@dataclass(frozen=True)
class DesignValidationReport:
    schema_version: int | None
    errors: tuple[str, ...]

def validate_design_report(document: object) -> DesignValidationReport:
    errors: list[str] = []
    # Require exact top-level and nested key sets, exact builtin JSON types,
    # stable IDs, global ID uniqueness, and resolvable design references.
    return DesignValidationReport(schema_version, tuple(sorted(errors)))

def validate_design(document: object) -> list[str]:
    return list(validate_design_report(document).errors)
```

```python
def design_identity_document(document: Mapping[str, Any]) -> dict[str, Any]:
    report = validate_design_report(document)
    if report.errors:
        raise ValueError("Design IR is invalid: " + "; ".join(report.errors))

def design_sha256(document: Mapping[str, Any]) -> str:
    return hashlib.sha256(
```

```python
@dataclass(frozen=True)
class DesignEnvelope:
    schema_version: int
    repository: str
    issue: str
    artifact_kind: str
    design_document: dict[str, Any]
    artifact_digest: str
    parent_digest: str
    policy_version: str
    config_digest: str

@dataclass(frozen=True)
class StoredDesign:
    envelope: DesignEnvelope
    device: int
    inode: int

class DesignEnvelopeStore:
    def store(
        self, *, repository: str, issue: str,
        document: Mapping[str, Any], parent_digest: str,
        policy_version: str, config_digest: str,
        expected_current_digest: str | None,
    ) -> StoredDesign: ...

    def read_current(self, *, repository: str, issue: str) -> StoredDesign | None: ...
    def read_digest(self, *, repository: str, issue: str,
                    digest: str) -> StoredDesign: ...
    def require_current(self, *, repository: str, issue: str,
                        digest: str, parent_digest: str,
                        policy_version: str,
                        config_digest: str) -> StoredDesign: ...
```

Store generations beneath the externally supplied controller store's
`generations/` directory using an opaque issue hash plus artifact digest. Store
a canonical current pointer separately. Create
the immutable generation first, authenticate it through a pinned descriptor,
then atomically replace the current pointer only when its prior digest equals
`expected_current_digest`. Never delete a generation in 0.3.0.
`read_current`, `read_digest`, and `require_current` always open with
`for_write=False`; an absent store returns `None` only from `read_current` and
must not create directories. Missing required generations and all corrupt or
unsafe state raise a typed store error.

`RunnerCapabilityDeclaration` names a trusted adapter source and declared set.
`CapabilityObservation` carries confirmed and failed subsets. Assessment rejects
overlap, removes failed values, and marks a required declared-but-unconfirmed
value as unverifiable. Required values not declared by any trusted source are
missing.

`capability_document` emits sorted source declarations, confirmations, failures,
effective values, missing values, and unverifiable values. `capability_sha256`
hashes that document with `artifact_sha256`.

Use immutable value records and validate them on construction:

```python
@dataclass(frozen=True)
class RunnerCapabilityDeclaration:
    schema_version: str
    source: str
    capabilities: frozenset[Capability]

@dataclass(frozen=True)
class CapabilityObservation:
    schema_version: str
    source: str
    confirmed: frozenset[Capability]
    failed: frozenset[Capability]

@dataclass(frozen=True)
class CapabilityAssessment:
    declarations: tuple[RunnerCapabilityDeclaration, ...]
    observations: tuple[CapabilityObservation, ...]
    declared: frozenset[Capability]

    failed: frozenset[Capability]
    effective: frozenset[Capability]
```

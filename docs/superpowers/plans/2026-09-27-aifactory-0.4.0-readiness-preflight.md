# AIFactory 0.4.0 Readiness Preflight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a public-safe 0.4.0 readiness preflight that fails closed until the roadmap's 0.4 entry criteria are satisfied by digest-bound evidence.

**Architecture:** Introduce a pure `release_readiness` module that validates a bounded redacted evidence summary and maps it to a deterministic readiness report. Add a `factory release readiness 0.4.0` CLI command as the operator-facing path. Keep evidence private: the public repo accepts only normalized criterion ids, states, digests, bounded summaries, and relative public-safe references.

**Tech Stack:** Python 3.10+, dataclasses, argparse, pytest, Ruff 0.16.0.

**Spec:** `docs/ROADMAP.md` and `docs/superpowers/specs/2026-09-26-aifactory-0.4.0-quality-verification-brief.md`

## Global Constraints

- Do not change `pyproject.toml` version or `software_factory.__version__`; this is preparation, not the 0.4.0 release.
- Do not add hard runtime dependencies; core-only import must remain dependency-free.
- Do not retain raw browser pages, unrestricted recordings, credentials, absolute paths, private hostnames, private repo names, or generated private evidence in the public tree.
- The preflight must fail closed when evidence is absent, malformed, incomplete, unavailable, vacuous, stale-looking, unsafe, or tied to the wrong release.
- End-user verification must exercise the CLI the way an operator would. Playwright is required only for browser/UI surfaces; this slice has no browser UI, so the relevant user-like tests are subprocess/CLI scenarios.

### Task 2: Operator-Facing CLI Preflight

**Files:**
- Modify: `software_factory/cli.py`
- Create: `tests/test_release_readiness_cli.py`

**Interfaces:**
- Consumes: Task 1 `evaluate_release_readiness` and report document.

```python
def test_operator_running_0_4_readiness_without_evidence_gets_blocked_json():
    result = subprocess.run(
        [sys.executable, "-m", "software_factory.cli", "release", "readiness", "0.4.0", "--json"],
        cwd=REPO_ROOT,
        text=True,
        capture_output=True,
    )

    assert result.returncode == 1
    document = json.loads(result.stdout)
    assert document["schema_version"] == "factory-release-readiness-report-v1"
    assert document["status"] == "blocked"
    assert "representative-t2-lifecycle" in document["blocking_criteria"]


def test_operator_running_0_4_readiness_with_synthetic_evidence_gets_ready_json(tmp_path):
    evidence = tmp_path / "readiness.json"
    evidence.write_text(json.dumps(_valid_document()), encoding="utf-8")

    result = subprocess.run(
        [
            sys.executable,
            "-m",
            "software_factory.cli",
            "release",
            "readiness",
            "0.4.0",
            "--evidence",
            str(evidence),
            "--json",
        ],
        cwd=REPO_ROOT,
        text=True,
        capture_output=True,
    )

    assert result.returncode == 0
    assert json.loads(result.stdout)["status"] == "ready"
```
